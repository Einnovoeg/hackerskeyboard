# Settings guide

Open the keyboard's settings from the gear key next to the space bar, from the
keyboard notification, or from **Settings → System → Languages & input →
On-screen keyboard → HACK3RS K3YB0ARD 3.0**.

The main screen is searchable: tap **Search settings** and type a name or keyword
(`oled`, `dvorak`, `lagoon`, `vibrate`, `gamepad`). Every row has a plain-language
summary, and appearance changes are previewed live.

## Keyboard size and layout

| Setting | What it does |
| --- | --- |
| Keyboard height, portrait / landscape | Sets the keyboard height as a percentage of the screen. The keyboard can also be resized by dragging its top edge or pinching. |
| Keyboard mode, portrait / landscape | Chooses Full (five rows), Compact, Phone, or the symbols layout per orientation. |
| Suggestions in landscape | Keeps the suggestion bar visible in landscape. |

## Key layout options

| Setting | What it does |
| --- | --- |
| Show settings key | Never, always, or automatically show the gear key. |
| Voice input | Chooses whether the microphone key appears in the main layout, symbols layout, or not at all. |
| Input languages | Selects the languages and layouts offered by the language-switch key. |

## Key behaviour

Auto-capitalisation, double-tap Shift behaviour (caps lock), modifier locking,
Ctrl+A override, and the physical keys used for chording Ctrl/Alt/Meta. Slide keys
turn swiping across the keyboard into cursor movement. The long-press duration
controls how long alternate characters take to appear.

## Keyboard customization

### Theme

- **Theme** — 30 themes, from the original Gingerbread/ICS look through Material,
  wood, ocean, forest, sunset, nebula, rose, sandstone, midnight, aurora, cyberpunk,
  paper and carbon, to the 3.0 palettes Lagoon, Ember, Cobalt, Blossom, Glacier and
  Obsidian.
- **Key glyph style** — arrows/spelled modifiers, macOS/Windows-style symbols,
  compact labels, lowercase and other alternate glyph sets.
- **Key style** — flat, outlined or raised key caps.
- **Key letter colour, font, bold and letter spacing** — control the labels.
- **Live preview** — reflects all of the above as you change it.

### Background

- **Background animation** — 16 options: None, Matrix rain, Starfield, Aurora,
  Scanlines, Rain, Bubbles, Neon grid, Fireflies, Plasma, Snow, Vortex, Ripples,
  Light beams, Liquid flow and Constellation.
- **Background image** — 24 high-resolution artworks, including the 2160 × 4800
  3.0 set. Choose **None** to use the theme background.
- **Background dim** — darkens the image or animation so key labels stay readable.
- **Live preview** — shows the current image, dimming and key styling.

### Keys

- **Key layout** — QWERTY, AZERTY or Dvorak for the five-row layout.
- **Key height, corner radius, cap opacity and shadow depth** — shape and depth of
  the key caps.
- **Bold labels, letter spacing, hint mode** — label weight, tracking and whether
  alternate characters are printed on keys.
- **Label scaling, suggestion scaling, fifth-row height** — size tuning for the
  keyboard text, suggestion bar and number row.
- **One-handed mode** — off, left or right; narrows the keyboard so it can be
  reached with one thumb.

### Lighting and key effects

- **Key press effect** — None, Glow, Ripple, Neon edge, Spark burst, Rainbow flash,
  Scanline sweep, Starlight or Shockwave accent on each touched key.
- **RGB lighting** — Off, Rainbow, Breathing, Wave, Reactive press or Static colour
  tinting across the key caps.
- **RGB animation speed, base colour and brightness** — tune the RGB animation to
  the theme and room.
- **Customize keys** — open the per-key editor to set a label, output text and text
  colour for any letter, number, symbol or modifier. Changes apply to the live
  keyboard immediately; individual keys or everything can be reset.

### Gamepad

- Button glyph set (Xbox, Switch, PlayStation).
- Pad theme and pad background.
- Swap sides for left/right-handed use.
- Live pad preview.

Tap the ⌘ key on the bottom row, then **Gamepad** to open the panel. Every button
sends a real controller key event. Enter ↑ ↑ ↓ ↓ ← → ← → B A for the hidden
Hackerman title card.

### Tools

Clipboard history, text snippets, macros and per-app theme rules. All data is stored
locally in the app's private storage.

### Advanced

- **Render mode** — hardware/software drawing selection where supported.
- **Touch positions** — draws touch coordinates for debugging.

## Typing and feedback

- **Speak keys / Speak whole words / Voice volume / Voice engine** — spoken feedback
  through Android TTS.
- **Autocorrect strength** — how aggressively corrections are applied.
- **Terminal-safe mode** — disables autocorrect in terminal apps such as Termux.
- **Vibrate on keypress and duration** — haptic feedback.
- **Sound on keypress, key sound pack and click volume** — system tone, ten
  mechanical keyboard packs, or spoken letters.
- **Popup on keypress** — shows the enlarged key preview while typing.

## Gestures and hardware keys

Assign actions to swiping up/down/left/right and to the volume-up/volume-down keys:
none, close keyboard, extension row, settings, suggestions, previous/next language,
full layout, clipboard, or keyboard height up/down.

## Prediction and input

Quick fixes, suggestion bar, auto-complete, suggested punctuation, recorrection,
fullscreen override in landscape, force-show keyboard, and the keyboard
notification.

## Application-specific options

- **ConnectBot Tab hack** — sends Tab correctly in ConnectBot.
- **Per-app themes** — choose a theme override for individual apps.

## Debugging

Touch-position overlay, current input-connection details (package, field and input
type) and the exact app version.

## Reset

Settings are stored in Android's app preferences and are included in Android
backup when enabled. To reset everything, clear the app's storage in Android
Settings; this also removes clipboard history, snippets, macros and per-app rules.
